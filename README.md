# 🎨 Mood Palette

A beautiful, intuitive web tool for extracting color palettes from images. Upload any image and instantly generate a professional color palette with customizable names and PDF export.

![Mood Palette Preview](https://img.shields.io/badge/Status-Live-brightgreen)

## ✨ Features

- **🖼️ Easy Image Upload** - Drag & drop or click to upload any image
- **🎯 Smart Color Extraction** - Uses k-means clustering algorithm to extract the 5 most prominent colors
- **📍 Interactive Color Indicators** - Drag color dots on the image to sample different areas
- **✏️ Customizable Labels** - Edit color names to match your project needs
- **📝 Live Title Preview** - See exactly how your title will appear in the PDF
- **🎨 Title Customization** - Adjust font, size, and alignment
- **📄 PDF Export** - Export your image with the color palette as a professional PDF
- **💾 One-Click Copy** - Click any color to copy its hex code to clipboard

## 📖 How to Use

1. **Upload an Image**
   - Click "Choose Image" or drag & drop an image file
   - Supports JPG, PNG, GIF, and WebP formats

2. **Review Extracted Colors**
   - 5 colors are automatically extracted from your image
   - Color indicators show where each color was sampled

3. **Customize Your Palette**
   - Drag color indicators to sample different areas
   - Click color names to edit them
   - Add a custom title above the image

4. **Export as PDF**
   - Click the "Export PDF" button
   - Your palette is saved with the image and color swatches

## 🛠️ Technical Details

- **Pure HTML/CSS/JavaScript** - No frameworks required
- **Client-Side Processing** - All color extraction happens in your browser
- **K-Means Algorithm** - Uses k-means clustering for accurate color extraction
- **PDF Generation** - Powered by jsPDF library
- **Responsive Design** - Works on desktop and tablet devices

## 💡 Tips & Tricks

- **Better Color Sampling**: Drag the color indicators to areas with pure versions of each color
- **Naming Convention**: Use descriptive names like "Ocean Blue" or "Sunset Orange" for better organization
- **PDF Quality**: Use high-resolution images for best PDF output quality
- **Multiple Palettes**: Export multiple variations with different titles to compare options
